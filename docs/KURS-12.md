# KURS-12 — бесплатные API для КурсМаяка

**Проверено 26 ноября 2026 года.** Предлагаемая схема использует **Bitstamp Public API** без регистрации и **Twelve Data Basic** с бесплатным ключом. Стоимость запросов в рамках указанных лимитов — **$0**. Bitstamp проверен живыми запросами для всех пяти нужных спотовых рынков. По USD/RUB у Twelve Data подтверждена доступность истории по документации. Для проверки текущей котировки и 30-дневного ряда нужен личный ключ Basic. [Bitstamp API](https://www.bitstamp.net/api/) · [Twelve Data Basic](https://twelvedata.com/pricing) · [Карточка USD/RUB](https://twelvedata.com/markets/787457/forex/usd-rub)

## Покрытие 12 пар

| Пары в боте | Источник или расчёт |
| --- | --- |
| BTC/USD, BTC/EUR, ETH/USD, ETH/EUR | Четыре прямых спотовых рынка Bitstamp |
| EUR/USD и USD/EUR | Спотовый рынок EUR/USD на Bitstamp и обратный курс |
| USD/RUB и RUB/USD | USD/RUB на Twelve Data и обратный курс |
| EUR/RUB и RUB/EUR | EUR/USD × USD/RUB и обратный курс |
| BTC/RUB и ETH/RUB | Курс BTC/USD или ETH/USD × USD/RUB |

Курсы с одним источником и составные курсы показываются с указанием поставщика. Составные курсы рассчитываются в `Decimal`. Для динамики берутся почасовые ряды за **1, 7 и 30 дней**. [Каталог пар](../infrastructure/db/catalog.py) · [Контракты проекта](../contracts.py) · [Хранилище котировок](../README.md#quote-storage)

Bitstamp даёт за один запрос до 1 000 часовых точек. Фактически проверена глубина 30 дней для каждой выбранной пары.

При повторной проверке Twelve Data справочник `GET /forex_pairs?symbol=USD/RUB` с ключом `demo` вернул HTTP 200 и подтвердил наличие USD/RUB в каталоге. Контрольная пара EUR/USD вернула текущий курс с меткой времени и 720 часовых записей. Оба запроса котировок USD/RUB снова вернули HTTP 401 с указанием использовать личный ключ. Проверка зафиксировала доступность обоих методов на контрольной паре. Доступ к данным USD/RUB на Basic, полноту его истории и свежесть нужно подтвердить с личным ключом. [Справочник валютных пар](https://support.twelvedata.com/en/articles/5620513-how-to-find-all-available-symbols-at-twelve-data) · [Карточка USD/RUB](https://twelvedata.com/markets/787457/forex/usd-rub)

## Квота и свежесть

- **Bitstamp:** один сборщик опрашивает все пять текущих курсов раз в минуту. Это 10 запросов за 10 минут при лимите 10 000. Сборщик сохраняет цену и метку времени поставщика в PostgreSQL. Конвертация и проверка порогов читают последний сохранённый снимок. [Лимиты Bitstamp](https://www.bitstamp.net/api/)
- **Twelve Data Basic:** один сборщик запрашивает только USD/RUB раз в две минуты. Это 720 кредитов в сутки и до 22 320 за 31 день. В обычные сутки остаётся 80 кредитов, в день с одним запросом истории — 79. Если каждый из двух фиатных символов опрашивать раз в две минуты, расход вырос бы до 1 440 кредитов в сутки. EUR/USD берётся из пакетного снимка Bitstamp. [Тариф Basic](https://twelvedata.com/pricing) · [Стоимость вызова](https://twelvedata.com/docs/currencies/exchange-rate)
- Для текущей цены сохранять `quoted_at` из ответа и `received_at` при приёме. Для обратного курса наследовать время исходной цены. Для составного курса брать более раннюю метку из двух компонентов. Показывать цену как актуальную и проверять пороги только при возрасте **не более 5 минут**. У двухминутного опроса USD/RUB есть запас по частоте, фактическую задержку источника нужно измерить отдельно.
- Почасовую историю получать один раз для всех пользователей и хранить в БД. Сопоставлять закрытия Bitstamp и Twelve Data по одному часу UTC. Если пропущен один компонент, составная точка отсутствует. При недостатке точек возвращать `HistoryIncomplete`. После загрузки рядов просмотр динамики и проверка уведомлений требуют **0 дополнительных запросов**. [Контракты проекта](../contracts.py)

## Пороговые уведомления

Проверять пороги сразу после получения нового свежего снимка по паре. При нормальном сборе новые цены Bitstamp проверяются с шагом до минуты, USD/RUB — с шагом до двух минут. Рублёвая криптоцена пересчитывается при обновлении любого компонента при условии, что оба свежие. Краткое пересечение между опросами может остаться незамеченным.

При срабатывании сохранить событие вместе с состоянием порога в одной транзакции. Сразу поставить событие на отправку и зафиксировать время первой попытки Telegram. Требование **NF_Alert_1** проверяется как `first_attempt_at − detected_at ≤ 60 секунд`. При повторной доставке использовать уже сохранённое событие. [Контракт `TriggerEvent`](../contracts.py)

## Исчерпание квоты и бесплатный резерв

- **Bitstamp.** При ограничении частоты распознавать код поставщика `400.002`. Повторять с паузой, используя `Retry-After`, если он присутствует. Сохранённая история остаётся доступной. [Коды и лимиты Bitstamp](https://www.bitstamp.net/api/)
- **Twelve Data.** При превышении квоты API сообщает код `429`. Минутный бюджет обновляется в начале следующей минуты, суточный — в **00:00 UTC**. Отдавать приоритет текущему сбору, историю загружать в пределах резерва. При исчерпании суток приостановить запросы, сохранить историю и при достижении лимита свежести показывать рублёвые пары как временно недоступные. [Кредиты Twelve Data](https://support.twelvedata.com/en/articles/5615854-credits)
- **Банк России.** Бесплатный источник справочного USD/RUB без ключа. `GET /scripts/XML_daily.asp` вернул HTTP 200 и курс USD с датой действия **26.11.2026**. `GET /scripts/XML_dynamic.asp` с кодом USD `R01235` вернул HTTP 200 и **22 дневные записи** с 27.10 по 26.11. Оба метода проверены. Для расчёта единичного курса делить `Value` на `Nominal`. Публикации в рабочие дни позволяют показывать отдельный справочный курс с датой действия. Для текущих RUB-порогов и почасовой динамики по нему данных недостаточно. [XML API Банка России](https://www.cbr.ru/development/sxml/) · [Порядок публикации](https://www.cbr.ru/faq/foreign_exchange_market/)

## Условия использования и итог

Бесплатный Basic у Twelve Data указан для внутреннего использования без показа данных. Для публичного бота право показа и распространения котировок Twelve Data требует отдельного подтверждения. Bitstamp отдельно оговаривает лицензию на коммерческое использование биржевых данных. [Тариф Basic](https://twelvedata.com/pricing) · [Условия Twelve Data](https://twelvedata.com/terms) · [Условия Bitstamp](https://www.bitstamp.net/api/)

Подтверждённый вариант без ключей покрывает шесть направлений без RUB по данным Bitstamp. Для рублёвых пар без ключа доступен справочный режим на данных Банка России. Полный вариант с почасовой историей и контролем пяти минут для всех 12 пар требует живой проверки двух методов USD/RUB с бесплатным ключом Basic, в том числе проверки возраста котировки вне активных торговых часов. Для публичного размещения бота также нужно подтвердить право показа данных.

Основание — F_Rate_5–7, F_Crypto_3–6, F_Dyn_1–9, NF_Data_1, NF_Alert_1 и HLD 5.
